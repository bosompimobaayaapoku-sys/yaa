# 🚀 Oddly Orbital

Welcome to my little corner of space!

Oddly Orbital is a space-themed website where creativity meets code. It features cosmic visuals, glowing cyan effects, smooth scrolling, and a Mission Control panel.

## ✨ Features
- Space-inspired visual design
- Mission Control panel with an active mission status
- Cyan glow and hover effects
- Smooth page scrolling

## 🛠️ Built With
- HTML
- CSS
